## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `pages/index.js`. The page auto-updates as you edit the file.

Copy `.env.sample` to `.env.local` first.

## Content API

The API and database this site used to call are gone. The content now lives in
`data/` and is served by an API built into this app under `pages/api/v1/*` —
see [docs/api.md](docs/api.md) for the endpoints, the query parameters they
accept and how to point the site back at an external API instead.
